Model values are always `provider/id`, and `PI_ACP_HIDE_PROVIDERS` leaves chosen providers' models out of the model option. For Pi 1.5.0 and above.

## Added

- `PI_ACP_HIDE_PROVIDERS`: a comma-separated list of Pi provider ids whose models are left out of the `model` option.
    - A value naming a hidden provider's model is refused with `invalid_params`.
    - A current model on a hidden provider is still reported as the option's `currentValue` while at least one model is listed.

## Changed

- The `model` config value is always `provider/id`, so a model's value stays the same when other providers start or stop offering its id. Prior releases sent the bare id unless another provider offered the same id.

## Compatibility

- A bare model value a client stored from a prior release is refused with `invalid_params`. Clients that echo the advertised values are unaffected.
