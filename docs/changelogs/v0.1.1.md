Model config option: bare model ids and provider-grouped selection. For Pi 0.84.4 and above.

## Changed

- The `model` config value is now the bare model id, prefixed with `<provider>/` only when more than one provider offers that id. This matches Pi's own reference-resolution rule: a bare id resolves when it is unique across providers, and an id shared across providers must be qualified. Prior releases always sent `provider/id`.
- The `model` option's values are grouped by provider (`SessionConfigSelectGroup`), so the provider appears once as a group header instead of repeating in every value.

## Compatibility

- The values a client sends to `session/set_config_option` for `model` must come from the option set the adapter returns (`config_option_update` and the `session/new` response), not be composed as `provider/id`. Clients that echo the advertised values are unaffected.
