A parent process can narrow each provider's models in the model option to the ones its endpoint listed. For Pi 1.5.0 and above.

## Added

- `PI_ACP_PROVIDER_MODELS`: a JSON object mapping Pi provider ids to non-empty arrays of model ids. A listed provider's models in the `model` option are those ids plus the session's current model; other providers are unchanged, and a group left empty is omitted.
    - A set still accepts every model of a visible provider, and the variable leaves the model Pi starts on as it is.
    - A `_acpStack/launch_env` request sets it in `env` or removes it in `unset`, for every model option built after the request.
    - A malformed value stops the adapter at startup, and refuses a launch env request with `invalid_params` naming the variable, never its value.
