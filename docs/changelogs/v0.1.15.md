The adapter moves to Pi 1.6.1 and ACP SDK 2.12.0, with no change to the ACP surface it offers. For Pi 1.6.1 and above.

## Changed

- ACP SDK 2.6.0 → 2.12.0 (schema v1.35.0). The adapter still speaks ACP v1 and advertises the same capabilities.

## Compatibility

- Pi releases below 1.6.1 are not verified; the dependency floor moved to `>=1.6.1`.
- Pi 1.6 changes what a client sees through the adapter:
    - Stopping a session's Pi waits for its pending work, for up to 6 seconds before the adapter kills it.
    - Pi warms the prompt cache between runs by default (since 1.5.1). The warming stops when an idle session's Pi stops, and its tokens fall outside every turn's `PromptResponse.usage`.
