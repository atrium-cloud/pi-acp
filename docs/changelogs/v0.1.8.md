Each adapter process writes its Pi extensions into a temp directory of its own. For Pi 1.3.0 and above.

## Fixed

- Each adapter process writes its Pi extensions into its own `mkdtemp` directory, removed when that process exits.
    - Prior releases named the directory after the process id, so adapters sharing a pid, as every sandboxed adapter is pid 1, shared one directory, and the first to exit removed the extensions of the others.
